# המעשנת — קטלוג סיטונאי

אתר סטטי. אין שרת ואין בסיס נתונים, ולכן אין דרך לתקוף אותו מבחוץ.
כל הנתונים יושבים בקובץ אחד שמגיע עם האתר: src/data.json

## העלאה לאוויר, פעם אחת

1. העלה את כל התיקייה למאגר בגיטהאב.
2. במאגר, לשונית ההגדרות, ואז דפים.
3. במקור בחר את הענף הראשי ואת התיקייה docs.
4. שמור. תוך דקה האתר עולה בכתובת שתופיע שם.

## עדכון מוצרים, מחירים וטעמים

1. פתח את האתר ולחץ על כפתור עריכת האתר.
2. ערוך מה שצריך. השינויים נשמרים בדפדפן שלך בלבד.
3. בפאנל, לחץ על הורדת קובץ נתונים.
4. במאגר, היכנס לקובץ src/data.json והחלף אותו בקובץ שהורדת.
5. הרץ בנייה מחדש והעלה את תיקיית docs המעודכנת.

לחלופין, אם מותקן אצלך מנהל החבילות:
npm install
npm run build

## למה זה מוגן

הפאנל בדפדפן עורך אך ורק עותק מקומי אצל מי שפתח אותו. גולש אקראי
שיפתח אותו לא משפיע על אף אחד אחר, כי אין שרת שמקבל את השינוי.
הדרך היחידה לשנות את מה שהלקוחות רואים היא להעלות קובץ למאגר,
וזה דורש את החשבון שלך.
